## 核心功能特色

* 📱 **手機優先（Mobile First）**：以 390px 寬度精心雕琢，直覺滑動與微立體翻頁體驗。
* 💡 **6 大實務分類 ✕ 104 題實戰引導**：涵蓋起步、破冰、試飲、跟進、體態與團隊夥伴陪伴。
* ☕ **傅姐專屬留言桌 ✕ 回信箱**：真誠一對一陪伴，夥伴寫便箋、傅姐後台溫暖叮嚀回覆。
* ☁️ **Supabase 即時雲端同步**：全台灣夥伴跨裝置留言即時匯入傅姐管理後台。
* 🎨 **專屬精裝書 App 圖示**：支援 iOS 與 Android 加入手機主畫面，隨點隨查。
